Usage:

``/imm helix toggle|on|off`` to change setting to close with a helix or not.

``/imm skillchain <property>|next|prev`` where ``<property>`` is a skillchain property, or another script in the ``misc`` directory to change the skillchain to make.  Note that current skillchain properties must begin with a capital letter.

``/imm cast`` to begin the skillchain cast.
